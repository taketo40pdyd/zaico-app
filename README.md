# 在庫管理アプリ（GitHub Pages 公開用）

バーコードで入出庫を記録できる在庫管理アプリです。ビルド不要の静的ファイルだけで動きます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（これだけで動作します） |
| `sw.js` | オフライン対応用のファイル。`index.html` と同じ場所に置きます |
| `404.html` | ページが見つからないときの表示（GitHub Pages が自動で使います） |
| `firestore.rules` | Firestore のセキュリティルール（Firebase に貼り付けます） |
| `.nojekyll` | GitHub Pages に、そのままのファイルを配信させる目印（空ファイル） |

## 公開の手順

1. GitHub で新しいリポジトリを作ります（例：`zaiko`）。
2. このフォルダの中身を、リポジトリの**いちばん上の階層**にアップロードします。
   - `index.html` がリポジトリ直下に来るようにしてください。
   - `.nojekyll` は、なくても動きます。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の Source を `Deploy from a branch` にし、Branch を `main`、フォルダを `/ (root)` にして **Save** します。
5. 数分待つと、次のアドレスで公開されます。

   ```
   https://ユーザー名.github.io/リポジトリ名/
   ```

## Firebase の設定（データ共有・ログインを使う場合）

設定情報（firebaseConfig）は `index.html` に埋め込み済みです。公開後に、Firebase コンソールで次を行ってください。

1. **Authentication → Sign-in method**
   「メール/パスワード」と「Google」を有効にします。
2. **Authentication → Settings → 承認済みドメイン**
   `ユーザー名.github.io` を追加します（`https://` や、リポジトリ名のパスは付けません）。
   これがないと、ログインで「承認済みドメインに入っていません」と表示されます。
3. **Firestore Database** を作成します。
4. **Firestore Database → ルール** に、`firestore.rules` の内容を貼り付けて **公開** します。
   メールアドレスの確認が済み、共有メンバーに登録された人だけが読み書きできます。
5. （おすすめ）Google Cloud コンソールの **APIとサービス → 認証情報** で、API キーの「HTTP リファラー」を
   `https://ユーザー名.github.io/*` に制限します。

> `apiKey` は秘密の鍵ではなく、公開されても問題ない識別子です。データを守っているのは、
> 上のセキュリティルールと承認済みドメインです。**ルールを公開していない（またはテストモードのまま）と、
> 誰でもデータにアクセスできてしまう**ので、必ず設定してください。

## 公開後に確認すること

- ページが開き、スマホではブラウザのメニューから「ホーム画面に追加」できる。
- 一度開いたあと、機内モードにしても画面が開く（オフライン対応）。
- ログインして、共有メンバーに自分のメールアドレスが表示される。

## 更新のしかた

1. `index.html` を新しいものに差し替えて、コミットします。
2. 利用者の画面には、新しいバージョンがあると「更新する」のお知らせが出ます。
   （`index.html` 内の `APP_VER` の数字が上がると、お知らせされます）

## 注意

- **データは、アドレス（ドメイン）ごとに別々に保存されます。** 手元のファイルを直接開いて使っていた在庫データは、
  公開したページには引き継がれません。先に「設定 → バックアップを保存（JSON）」で書き出し、
  公開したページで「バックアップから復元」してください。
- データ共有をオンにすると、メンバー間で同じ在庫を使えます。オフにした端末には、その端末のデータが残ります。
- 無料の GitHub Pages は、公開リポジトリが前提です（有料プランでは非公開リポジトリも使えます）。
  アプリの画面は誰でも開けますが、在庫データ（Firebase 側）は、登録したメンバーしか見られません。
